## 说明:

### 量子记账功能

先手动执行[记账初始化]脚本，执行一次即可，目的是初始化数据管理标题

日统计，会每日进行数据统计，当天账单会通知。

月统计，会每月1号进行数据统计，会对上月账单进行通知。

例如：

支出公交2，即支出2元，标签为公交。
支出午餐20，即支出20元，标签为午餐。
必要支出话费100，即支出100元，标签为话费，且该项为必要支出
支出礼物500送给女朋友，即支出500元，标签为礼物，备注为送给女朋友

收入工资20000，即收入20000完，标签为工资
收入其他20捡钱了，即收入20元，标签为其他，备注为捡钱了

建议规范记账标签，后续将通过标签进行数据统计。丰富更多的报表。
